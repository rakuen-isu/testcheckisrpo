
# TestCheck ISRPO

**TestCheck ISRPO** — расширение для Visual Studio Code, предназначенное для автоматической компиляции и тестирования программ на C++ с использованием заранее подготовленных тестов.


## Возможности

- **Автоматическая компиляция** — компиляция C++ программ с помощью GCC.
- **Пользовательские тесты** — поддержка тестовых файлов с числовыми и произвольными именами.
- **Автоматический запуск тестов** — последовательное выполнение всех найденных тестов.
- **Сравнение результатов** — сравнение фактического и ожидаемого вывода.
- **Измерение времени выполнения** — определение времени выполнения каждого теста.
- **Ограничение времени выполнения** — автоматическая остановка программы при превышении установленного лимита.
- **Обработка ошибок** — определение ошибок выполнения, несовпадений результатов и превышения времени.
- **Интерактивная панель** — отображение статистики, круговой диаграммы и подробной таблицы результатов.

## Требования

Для работы расширения необходимы:

- Visual Studio Code версии 1.141 или новее.
- GCC (`g++`), установленный и доступный через системный PATH.
- Node.js и npm (для разработки расширения).

## Установка

### Установка из VSIX-файла

1. Получите файл `testcheckisrpo-0.0.1.vsix`.
2. Откройте Visual Studio Code.
3. Перейдите в раздел Extensions.
4. Откройте меню с тремя точками.
5. Выберите **Install from VSIX...**.
6. Укажите путь к скачанному файлу.

## Использование

1. Откройте проект с исходным файлом C++ в Visual Studio Code.
2. Создайте в корневой папке проекта каталог `tests`.
3. Добавьте в него входные и ожидаемые выходные файлы тестов формата x.in, x.out.
4. Откройте исходный файл C++.
5. Вызовите командную палитру сочетанием `Ctrl + Shift + P`.
6. Выполните команду **Run Tests**.

Расширение автоматически скомпилирует активный файл C++, запустит найденные тесты и покажет результаты.

## Структура тестов

Каждый тест состоит из двух файлов с одинаковым именем:

- `.in` — входные данные.
- `.out` — ожидаемый результат выполнения программы.

Пример структуры проекта:

```text
project/
├── main.cpp
└── tests/
    ├── example.in
    └── example.out
```

## Пример работы

Входной файл `tests/example.in`:

```text
5
```

Ожидаемый результат `tests/example.out`:

```text
10
```

Исходный код `main.cpp`:

```cpp
#include <iostream>

int main() {
    int x;
    std::cin >> x;

    std::cout << x * 2 << '\n';

    return 0;
}
```

Если программа выводит ожидаемый результат, тест получает статус **Passed**.

## Статусы тестирования

| Статус | Описание |
|---|---|
| Passed | Фактический результат совпадает с ожидаемым. |
| Failed | Фактический результат отличается от ожидаемого. |
| Error | Произошла ошибка выполнения программы или обработки теста. |
| Timeout | Программа превысила установленное время выполнения. |

## Панель результатов (Dashboard)

После выполнения тестов открывается интерактивная панель, содержащая:

- Общее количество тестов.
- Количество успешно пройденных тестов.
- Количество неудачных тестов.
- Количество ошибок и превышений времени.
- Круговую диаграмму результатов.
- Таблицу с названиями тестов, статусами и временем выполнения.
- Ожидаемый и фактический вывод для тестов с ошибочным результатом.

## Разработка

Клонирование репозитория:

```bash
git clone https://github.com/rakuen-isu/testcheckisrpo.git
```

Установка зависимостей:

```bash
npm install
```

Компиляция расширения:

```bash
npm run compile
```

Для запуска расширения в режиме разработки откройте проект в VS Code и запустите конфигурацию **Run Extension** через раздел Run and Debug.
